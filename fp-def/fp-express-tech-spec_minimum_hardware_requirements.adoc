== FlexPod Express with NetApp AFF/ASA/FAS

The hardware requirements for FlexPod Express solutions that use NetApp AFF, ASA, or FAS controllers for underlying storage include the configurations described in this section.

The minimum hardware requirement for FlexPod Express is listed below:

* Two 10Gbps standard Ethernet switches in a redundant configuration (Cisco Nexus 9200 and 9300 models)
* Cisco UCS C-Series standalone rack servers with CIMC based standalone rack server configuration or Intersight-managed configuration or the UCS X-Series Direct with Cisco Intersight-managed configuration
* Two entry-level NetApp AFF (A20, A30, or C30), NetApp ASA (A20, A30, or C30), or NetApp FAS (2750 or 2820) series controllers in a high-availability (HA) pair configuration deployed as a two-node cluster
