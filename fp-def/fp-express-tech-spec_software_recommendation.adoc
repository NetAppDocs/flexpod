This section describes the software version recommendations for FlexPod Express.

* ONTAP version : 9.16

* Cisco NX-OS version : For the general recommendation of Cisco NX-OS version for the cisco 9000 series switches, refer to link:https://www.cisco.com/c/en/us/td/docs/switches/datacenter/nexus9000/sw/recommended_release/b_Minimum_and_Recommended_Cisco_NX-OS_Releases_for_Cisco_Nexus_9000_Series_Switches.html[Recommended Cisco NX-OS Releases for Cisco Nexus 9000 Series Switches^] 

[NOTE]
All software components must be listed and supported in the http://support.netapp.com/matrix/[NetApp IMT^], All NetApp hardware components and ONTAP versions must be listed and supported on https://hwu.netapp.com/Home/Index[NetApp Hardware Universe^] and All Cisco hardware components must be listed and supported on https://ucshcltool.cloudapps.cisco.com/public/[Cisco HCL^].
