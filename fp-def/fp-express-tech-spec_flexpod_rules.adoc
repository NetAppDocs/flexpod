= FlexPod Rules
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./../media/


[.lead]
The FlexPod design supports a flexible infrastructure architecture that encompasses a variety of hardware components and software versions.

Use the rule sets as a guide for building or assembling a valid FlexPod configuration. The numbers and rules listed in this document represent the minimum requirements for FlexPod and can be expanded by using supported products within the included product families as required for different environments and use cases.
